# Sentinelle (nom provisoire)

Bot de trading crypto 24 h/24, piloté depuis Telegram et depuis un logiciel de gestion dédié, avec analyse des actualités par IA.

**Sécurité d'abord** : simulation (argent fictif) par défaut, gestionnaire de risque avec droit de veto sur toutes les décisions, mode réel verrouillé tant que le bot n'a pas fait ses preuves.

> **Avertissement** : le trading comporte un risque de perte en capital. Aucun bot ne peut garantir des gains. Ce projet ne constitue pas un conseil financier.
